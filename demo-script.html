3-Minute Demo Script

Manager Self-Service Dashboard — Hackathon Demo Flow

Click action
Page/location
Key talking point
Emphasis
0:00 – 0:20 Login & First Impression
"I'm a manager at Acme Corp. I sign in with my regular Okta credentials — no admin access, no special privileges."
  • Start on Login page
  • Click "Sign in with Okta" — OIDC redirect, authenticate
  • Land on Dashboard — pause to let it load
  • Point out the two overview cards: Direct Reports count and Pending Reviews count
0:20 – 0:50 My Team — Who Reports to Me
"The first thing customers ask for: let me see my team. Here are all my direct reports with their status, last login, and whether they have a delegate assigned."
  • Scroll down to Team Members table on dashboard
  • Point out columns: name, email, title, status badges, last login, delegates
  • Type in the search box — show live filtering by name
  • Open the status dropdown, select "Suspended" — show server-side filtering
  • Reset to "All Statuses"
  • Click the Status column header — show sort (Active → Provisioned → Suspended → Deprovisioned)
  • Key point: "All of this is live from Okta's Management API — not cached, not mocked."
0:50 – 1:20 Member Detail — What Do They Have Access To?
"Let's drill into a team member. I can see everything they have access to — apps, roles, and groups — all from Okta's APIs."
  • Click a team member's name to open Member Detail
  • Point out the profile header: name, email, title, status, last login
  • Click "Apps & Entitlements" tab — show assigned apps with role badges
  • Briefly scroll through the app cards
  • Click "Groups" tab — show group memberships
  • Key point: "A manager can now answer 'what does this person have access to?' without asking IT."
1:20 – 1:50 Start an Access Review
"Now the powerful part. I can kick off an access review campaign for my team — right from this dashboard."
  • Click "Start Review" button in quick actions (or navigate to Reviews → Create)
  • Show the create form: campaign name is pre-filled, direct reports are pre-selected
  • Point out you can exclude specific users if needed
  • Click "Create Campaign" — campaign is created in Okta via the Governance API
  • Key point: "This just created a real certification campaign in Okta. Two clicks. No admin console."
1:50 – 2:15 Review Pending Certifications
"I also have pending reviews from other campaigns that need my attention. Let's look at those."
  • Click "Access Reviews" in the sidebar (or click the Pending Reviews card on dashboard)
  • Show Reviews page with active campaigns and pending counts
  • Point out campaign cards with due dates and pending review counts
  • Key point: "Everything a manager needs to stay on top of governance — in one place."
2:15 – 2:45 Set a Governance Delegate for PTO
"Last piece: I'm going on vacation. I need someone to cover my reviews while I'm out. I can set that up myself."
  • Click "Set Governance Delegates" in the sidebar
  • Show the Settings page with delegate assignment form
  • Search for a delegate user in the search field
  • Select scopes (Reviews, Requests) and set start/end dates
  • Click "Assign Delegate" — delegation created via Okta Delegates API
  • Point out the delegate now appears in the Active Delegates list
  • Key point: "No reviews go stale. Governance continues even when I'm out."
2:45 – 3:00 Wrap Up
"That's the manager journey: see my team, review their access, start campaigns, set delegates — all without admin access, all powered by Okta's APIs. This is the feature customers keep asking for."
  • Click "End User Dashboard" in sidebar — show the link back to Okta
  • Final point: "6 Okta API families. Dual-auth pattern. Built with Claude Code as AI pair-programmer. Production-ready."

Demo Tips

  • Pre-login before the demo starts so OIDC redirect is fast (session already warm)
  • Have at least one active campaign with pending reviews to show on the Reviews page
  • Pick a team member who has several apps assigned for a rich detail view
  • If something loads slow, talk through the architecture while it loads: "This is hitting the Okta API in real-time..."
  • Toggle dark mode by clicking the shield logo if you want a visual "wow" moment
  • If time is tight, skip the certification review step (beat 5) — the create campaign step is more impactful
